Sound Lab

Every game sound has a version generated in code (packages/client/src/audio.ts) and, where a good free recording exists, one or more CC0 samples (public/sfx, listed in sfx-manifest.ts and CREDITS.md). Tap a version to hear it; tick use to make this browser's game use it.

Picks are stored in localStorage["tank.sfxPicks"], which only the game served from this same host and port can see. To use them elsewhere, run the line below in that page's console (or send the JSON to update the defaults in sfx-manifest.ts).

Renders every synth version offline and decodes every sample, then measures them the same way: K-weighted loudness (roughly as ears hear it) of the loudest 400 ms, or the average for loops. Samples carry a gain in the manifest so they sit at the synth version's loudness; "vs synth" should stay within a dB or two.
